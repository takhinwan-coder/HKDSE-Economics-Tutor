# 導師備課筆記：Topic 6 廠商擁有權、擴張及結合

> 主修 B 第 4 課｜預計課堂：70–75 分鐘｜本檔包含學生講義全部答案

## 教學目標

- 學生能解釋規模經濟／不經濟，以平均成本資料辨認其方向，並和短期遞減邊際報酬區分。
- 學生能說出獨資、合夥和有限公司的基本特徵及責任差異。
- 學生能分辨內部擴張和外部擴張，並按供應鏈位置分類結合。
- 學生能簡述工序／職業分工與地區分工。

## 課前準備

- 分享學生講義的分工圖、規模效果圖，以及擁有權／擴張與結合圖；先確認 PDF 圖像和文字沒有被裁切。
- 白板預備公式：`平均成本 = 總成本 ÷ 產量`；供應鏈：`農場 → 製造商 → 配送商 → 零售店 → 消費者`。
- 數值練習逐次使用「找已知及所求 → 選公式 → 代入 → 計算 → 寫單位和解讀」，完成第一題後再減少提示。
- 2025 更新指引所排除的是特定成本曲線的一般關係，不等同刪除規模經濟／不經濟。規模相關更細子項和校內分類術語仍須對照 syllabus 及 Ch.03/相關筆記確認；不畫曲線或推導短期與長期成本曲線關係。

## 必須教會

- 規模經濟＝長期規模擴大時平均成本下降；規模不經濟＝規模擴大時平均成本上升。
- 比較規模變化時看平均成本，不可只看總成本；規模變大不保證平均成本下降。
- 規模效果是長期平均成本概念；遞減邊際報酬是短期固定其他投入、邊際產量最終下降，兩者不能互換。
- 獨資、合夥、有限公司的擁有權和責任差異；有限責任不代表不會虧損。
- 自行擴充資源是內部擴張；收購或合併其他廠商屬外部擴張，再按生產階段及供應鏈位置分類。
- 地區分工是不同地區專門生產不同產品/服務並交換；沿用校內術語前先核對筆記。

## 預期困難與補救

| 常見誤解 | 補救問題 |
|---|---|
| 總成本上升就代表規模不經濟 | 「每單位平均成本怎樣變？先各自除以產量。」 |
| 把規模經濟當成遞減邊際報酬 | 「是長期所有投入可變，還是短期有投入固定？比較的是 AC 還是 MP？」 |
| 算式做對但不知數值意思 | 要求補上 `$ / 箱` 並說明 AC 上升/下降，最後才命名規模效果。 |
| 所有合併都是水平結合 | 「兩間廠商是否在同一生產階段？在供應鏈哪個位置？」 |
| 混淆向前和向後垂直結合 | 從零售商往上游供應商是向後；往配送／顧客方向是向前。 |
| 有限責任代表股東不會虧損 | 「股東投資仍可能損失嗎？有限的是哪一種責任？」 |

## 學生講義逐題答案（導師專用）

### 快問快答

1. 規模經濟是長期規模擴大時平均成本下降；規模不經濟是規模擴大時平均成本上升。
2. 地區分工；不同地區各自集中生產某類產品，再透過交易互相供應。
3. 內部擴張；餐廳用自己的資源開新店，沒有合併或收購另一廠商。
4. 水平結合；兩間零售商處於同一生產階段並售賣同類產品。
5. 股東通常只承擔其投資額內的損失，屬有限責任。

### 選擇題

1. **A。**規模擴大而平均成本下降是規模經濟；B 指平均成本上升；C 是短期生產概念，不是長期平均成本概念；D 與題目給的平均成本變化無關。
2. **B。**管理、溝通和協調困難令平均成本上升，屬規模不經濟；A 的平均成本方向相反；C 涉及短期邊際產量；D 是擴張方式，不是成本效果。
3. **B。**有限責任通常把股東損失限於投資額；A 是無限責任；C 錯把責任形式當成盈利保證；D 錯，公司仍可籌資。
4. **B。**同一階段、同類貨品的兩間廠商結合是水平結合；A 是廠商自行增資源；C 涉及不同但有供應關係的階段；D 是沒有直接供應鏈關係的業務。
5. **D。**電影公司與茶飲店沒有直接供應鏈關係，屬混合結合；A 要同階段同類業務；B/C 分別是收購上游/下游供應鏈廠商。

### 結構式題目

1. 內部擴張（1 分）。
2. 公司與股東在法律上分開（1）；股東通常只承擔投資額內的損失，不必以全部私人資產承擔公司債務（1）。
3. 向後垂直結合（1）；麵粉供應商是餅店的上游投入品供應者（1）。
4. 優點例子：決策快或東主保留利潤（1）；限制例子：資金來源較有限或通常承擔無限責任（1）。
5. 原平均成本：`$1,000 ÷ 100 = $10/箱`（1）；擴大後：`$1,600 ÷ 200 = $8/箱`（1）；平均成本下降，出現規模經濟（1）。

### 課後練習

1. 原平均成本：`$1,200 ÷ 100 = $12/箱`；擴大後：`$1,650 ÷ 150 = $11/箱`。平均成本下降，顯示規模經濟。
2. (a) 內部擴張：自行聘人和添置設備；(b) 水平結合：同類茶飲店；(c) 向後垂直結合：茶葉農場是上游供應者；(d) 向前垂直結合：送貨公司位於通往顧客的下游；(e) 混合結合：沒有直接供應鏈關係。分類和理由須配合。
3. 獨資由一名東主擁有，通常承擔無限責任，集資較受個人資源限制；有限公司是獨立法律實體，股東通常有限責任，並可透過股份等方式籌資。
4. 地區分工（1）；甲、乙地各自集中生產某類產品，再透過交易取得另一地產品（1）。
