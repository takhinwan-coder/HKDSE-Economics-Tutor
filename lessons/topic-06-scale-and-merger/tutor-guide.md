# 導師備課筆記：Topic 6 規模經濟、廠商擴張與結合

> 主修 B｜預計 70–75 分鐘｜本檔包含學生講義全部答案

## 教學目標

- 用平均成本解釋內部／外部規模經濟和規模負經濟，並舉出可能成因。
- 分清長期規模效果與短期遞減邊際報酬。
- 分類縱向、橫向、側向和集團結合，並解釋可能動機。

## 課前準備

- 使用 `scale-effects.svg` 說明 AC 方向；不畫成本曲線。
- 白板預備公式 `AC = TC ÷ Q` 和供應鏈 `供應商 → 製造商 → 配送 → 零售 → 顧客`。
- 本課不要求把內部／外部經濟和負經濟細分成更多類別；依 2025 更新版 supplementary document p.11，只用平均成本說明，提供可能原因即可。
- 不教成立結合的方法或程序。若談收購／合併，只作日常語境，不作考核內容。

## 課堂流程

| 時間 | 教學環節 | 提示 |
|---|---|---|
| 0–5 分鐘 | 銜接 Topic 5 | 口頭比較短期 MP 與長期 AC。 |
| 5–22 分鐘 | 規模效果定義 | 先計 AC，再分辨原因來自個別廠商還是整個行業。 |
| 22–32 分鐘 | 可能成因 | 學生各舉一個規模經濟及負經濟原因；提醒規模變大不保證成本下降。 |
| 32–39 分鐘 | 與遞減邊際報酬比較 | 按時期、改變投入、衡量指標填比較表。 |
| 39–54 分鐘 | 結合類型 | 用供應鏈定位縱向，再比較同產品橫向、相關產品側向及不相關市場集團。 |
| 54–64 分鐘 | 結合動機 | 要求「類型 → 可能動機 → 因果」完整回答，不把動機說成必然結果。 |
| 64–72 分鐘 | 練習 | 完成結構題，學生每次都須寫 AC 單位及分類線索。 |
| 72–75 分鐘 | Exit ticket | 以一句話分別定義外部規模經濟、側向結合。 |

## 必須教會／不要求

- AC 下降是規模經濟，AC 上升是規模負經濟；總成本變化本身不足以判斷。
- 內部成因來自廠商自身規模，外部成因來自行業擴大或行業環境改變。
- 長期規模效果比較 AC；短期遞減邊際報酬比較 MP。
- 結合四類及可能動機；不教授法律／商業結合方法或成本曲線。
- 保留縱向結合的方向判斷：向後是上游供應商，向前是下游配送／零售。

## 預期困難與補救

| 常見誤解 | 補救提示 |
|---|---|
| 總成本上升等於規模負經濟 | 讓學生先計兩個時期的 AC。 |
| 外部規模經濟是某廠商自己擴大 | 問「改變來自個別廠商，還是整個行業環境？」 |
| 側向與集團結合相同 | 比較產品是否同階段且相關；不相關才是集團結合。 |
| 縱向結合方向說反 | 在供應鏈標出廠商位置；向投入品端是上游，向顧客端是下游。 |
| 結合必然降低成本 | 追問整合成本、管理困難是否可能造成規模負經濟。 |

## 學生講義答案

### 快問快答

1. 分別用總成本除以產量計算兩個時期 AC，再比較每單位成本；總成本上升不妨礙 AC 下降。
2. 外部規模經濟，因成本下降來自行業擴大及行業內可用的供應商／勞工增加。
3. 管理層級過多、溝通和監督困難、部門協調成本上升，任何合理例子均可。
4. 橫向結合；可能擴大市場佔有率、增加顧客或減少競爭。
5. 側向結合：生產階段相同，產品不同但相關。

### 選擇題

1. **A。**AC 由 $12 降至 $10，屬規模經濟；B 方向相反；C 衡量短期 MP；D 指擴張方式，不能解釋 AC 變化。
2. **B。**整個行業擴大並改善共同勞工來源，屬外部規模經濟；A 由個別廠商內部擴大造成；C 是 AC 上升；D 是短期生產概念。
3. **B。**零售商與供應商在同一供應鏈不同階段，屬縱向結合；其餘類型不符合上下游關係。
4. **C。**同階段、不同但相關產品屬側向；橫向通常是同階段的相同／相似產品；縱向指不同供應鏈階段；集團指不相關行業。
5. **C。**集團結合的可能動機是分散至不相關市場；A、D 是縱向動機；B 是橫向動機。

### 結構式題目

1. 規模經濟，因 AC 下降（1）。
2. 內部規模經濟（1），原因是安樂食品自身擴大／採用專門設備令其 AC 下降（1）。
3. 側向結合（1）；可能擴闊產品種類或顧客群（1）。
4. 管理、溝通、監督或協調變困難，令內部成本上升（1）。

### 課後練習

1. 專門供應商和熟練工人因行業聚集而增加，令多家區內廠商更容易取得投入品／勞力，平均成本可能下降（1）；屬外部規模經濟（1）。
2. (a) 橫向結合；擴大市場佔有率或減少競爭。(b) 縱向結合；穩定供應或控制銷售渠道。(c) 側向結合；擴闊相關產品種類。(d) 集團結合；分散市場／業務風險。每題類型和合理動機均須相符。
