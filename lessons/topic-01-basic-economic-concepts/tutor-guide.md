# 導師備課筆記：基本經濟概念（一）

> Topic 1 備存教材｜預計課堂：75 分鐘｜學生先備知識：假設沒有；不屬目前主修 B 四課

## 教學目標

- 學生能用生活例子說明資源有限、慾望眾多與選擇的關係。
- 學生能正確辨認選擇、次佳選擇和機會成本。
- 學生不再把機會成本只理解為所選物品的價格或金錢支出。
- 建立輕鬆的提問與答題習慣，了解學生目前對經濟學的想法。
- 學生能用完整因果句解釋稀少性如何導致選擇，以及選擇如何涉及機會成本。

## 概念講解：導師可用的說明與追問

### 1. 經濟學為甚麼從稀少性開始？

可先說：「我們每天有很多想做或想要的事，但可用的時間、金錢和其他資源有限。經濟學會研究個人和社會如何運用這些有限資源去滿足慾望。」這不是說每個人都很窮，也不是說所有資源都完全沒有，而是說在某個情況下，資源不足以同時滿足所有想要的用途。

用三步因果鏈寫在白板：

**慾望眾多 + 資源有限 → 資源不足以滿足所有慾望（稀少性） → 必須選擇**

逐步提問：

1. 「如果你今晚有兩小時，想溫習、打機、運動和休息，兩小時夠不夠全部做？」
2. 「令你不能全部做的限制是甚麼？」引導學生說出時間有限，而不是「因為不想」。
3. 「如果多一小時，選擇會不會改變？」讓學生看到稀少性與可用資源、慾望及具體情況有關。

**理解檢查：**「一間店有很多支筆，所以筆一定不稀少，對嗎？」引導學生補充比較基準：對某個人、某段時間或某種用途而言，是否仍不足以滿足所有需要。不要把稀少性簡化成「數量少」或「很罕有」。

### 2. 資源有限為甚麼會帶來選擇？

「選擇」不只是購物時挑商品。時間、金錢、座位和注意力都可以用在不同地方；同一資源一旦用在某個用途，通常就不能同時完整地用在其他用途。這就是取捨。

回到 $60 情境，先請學生說出想買的所有東西，再指出預算限制和可行選項。追問「如果多 $20，選擇會否不同？」、「如果文具是明天必須交功課用，偏好排序會否改變？」讓學生理解決定會受限制和情況影響，而不是只有一個固定的「正確偏好」。

板書可用：

| 資源 | 可作的不同用途 | 造成的限制 |
|---|---|---|
| $60 零用錢 | 午餐、飲品、文具、儲蓄 | 不能同時買下所有想要的東西 |
| 放學後一小時 | 做功課、休息、運動、補習 | 時間用於一項活動後，不能再完整用於其他活動 |

**教學提醒：**學生只要指出一項真實限制及因此要取捨即可，不必要求他證明自己一定選了「最理性」的方案。本課重點是看懂選擇與放棄，不是評價學生的喜好。

### 3. 甚麼是次佳選擇？如何找到機會成本？

先強調機會成本不是把所有沒選的東西列出來，而是找出在已放棄的可行選項中，自己最想選的那一項，再說明放棄它所失去的價值。

白板固定用以下四步：

1. **已作出的選擇：**小晴買三文治。
2. **其他可行選項：**檸檬茶、文具等。
3. **最佳被放棄選擇：**小晴表示若不買三文治，她最想買檸檬茶。
4. **機會成本：**放棄檸檬茶所得到的價值。

完整說法：「小晴選擇買三文治。她放棄的選擇中，價值最高的是檸檬茶，因此她買三文治的機會成本是放棄檸檬茶所得的價值。」這裡的「價值」可以是滿足或其他好處，不等於飲品的標價。

追問學生：「如果她實際最想買的是文具，答案還會是檸檬茶嗎？」答案應按題目給出的偏好改變；不要只看哪件物品最貴。若題目已交代「最想要」或「最佳替代選擇」，以該資訊判斷。

### 4. 價格、金錢支出與機會成本有甚麼分別？

用「三文治售價 $45」作對照：

- **價格／支出：**買三文治要付出的 $45。
- **機會成本：**因選擇三文治而放棄的最佳替代選擇之價值。

兩者有時都以金錢表示，但概念不同；題目若明確給出兼職收入作為被放棄的最佳選擇價值，可按題目資料用該金額作答。不要只因題目出現價格，就把價格抄成機會成本。

**反例追問：**「公園免費入場，所以去公園一定沒有機會成本嗎？」引導學生想交通和時間，以及同一段時間原本最想做甚麼。免費只表示沒有入場費，不表示沒有被放棄的選擇。

**答題完整句框：**「我選擇＿＿；被放棄的可行選項中，價值最高的是＿＿；所以機會成本是放棄＿＿所得的價值。」

### 5. 如何解釋稀少性題目，而不只背定義？

如果題目問「稀少性如何令某人作出選擇」，按以下因果順序說明：

1. 指出有限資源，例如只有三小時或有限零用錢；
2. 指出想要的用途不止一項；
3. 說明資源不足以同時滿足所有用途，因此要在用途之間作選擇。

以嘉怡題目示範：「嘉怡星期六下午只有三小時，但她可以溫習、做兼職或看電影。時間有限，不能同時用於所有活動，因此她要在這些用途之間作出選擇。」要求學生把題目資料代入，不要只寫「因為稀少所以要選擇」而沒有指出限制和競爭用途。

## 必須教會

- 稀少性是相對於慾望而言資源不足；不等於罕有、昂貴或資源完全不存在。
- 資源有不同用途；因此人需要在可行選擇中取捨。
- 機會成本是被放棄選擇中**價值最高的一項**，不是所有未選選項的總和。
- 機會成本不必是金錢支出；要說明被放棄選擇的價值。
- 解釋題要交代題目中的有限資源、競爭用途，以及因此要作出的選擇。

## 可選內容

- 經濟物品與免費物品的區別；若討論，強調同一物品會因時間/地點/可用數量改變而有不同稀少程度，勿把「零售價」直接等同有沒有機會成本。
- 三個基本經濟問題、社會機制、私有產權、專業化與交易、經濟活動循環流程，以及實證/規範陳述。它們都在課程指引的 A 部分，但不屬於本堂核心，建議後續課堂分開處理。

## 預期困難與補救

| 學生可能的錯誤/疑問 | 追問或解釋方式 |
|---|---|
| 「稀少就是很罕有。」 | 問：「你的溫習時間在考試前是否很珍貴？它罕有嗎？有限的是甚麼？」帶回相對於其他用途的不足。 |
| 把稀少性說成「物品數量少」，沒有提及慾望或用途。 | 問：「對誰而言？在甚麼時間或情況下？有限數量是否足以滿足他想做的所有事情？」要求學生補上相對於慾望的限制。 |
| 認為選擇是隨便挑一樣，沒有取捨。 | 問：「你選了這個之後，哪個用途不能再做？如果資源多一點會否不同？」把答案連回資源的不同用途。 |
| 把機會成本答成已選物品的價格。 | 問：「如果這件物品免費，但你仍放棄休息去排隊領取，是否有放棄其他選擇？」 |
| 把所有未選選項加起來。 | 讓學生按偏好排序，只問「若不能選原本那項，下一個最想選甚麼？」 |
| 只寫放棄選擇，未說價值。 | 用完整句框：「機會成本是放棄＿＿所得到的價值。」 |
| 認為免費活動沒有機會成本。 | 分開金錢價格與時間用途；活動可免費，但參加者仍可能放棄其他用途。 |
| 只背「最高價值」但把最高價格當成最高價值。 | 問：「題目給的是售價，還是告訴你最想要哪個選擇？價值要按題目所述的偏好或資料判斷。」 |

## 練習答案及評分提示

> 對應學生講義：[student-pack.md](./student-pack.md)。以下為教學用自編練習，不是歷屆試題原題。

### 快問快答

1. 去公園可能放棄了做功課、休息或其他活動；其中價值最高的被放棄選擇是機會成本。免費入場不代表沒有時間成本。
2. 若兼職是小明最好的另一個選擇，機會成本是放棄這兩小時兼職可賺取的收入（按題目情境為 $160），而不是溫習所花的金錢。
3. 不正確。價格是金錢支出；機會成本是作出選擇時放棄的價值最高選擇的價值。
4. 不是。稀少性是指資源相對於慾望不足，並不必然代表資源在自然界很罕有。

### 選擇題

1. **B**。A 錯，經濟選擇不一定要付費，例如分配時間；B 對，資源有限而慾望眾多，令個人和社會需要取捨；C 錯，即使人能作理性選擇，稀少性仍然存在；D 錯，價格變化可能影響選擇，但不是經濟問題的根源。
2. **B**。A 錯，只指出選擇多，沒有說明資源不足以應付慾望；B 對，小欣只有一小時，但希望做兩件事，必須取捨；C 錯，高價格不等同稀少性的定義，題目沒有交代資源與慾望；D 錯，受歡迎不一定代表資源不足。
3. **C**。A 錯，$50 是午餐價格，不是題目所述次佳選擇的價值；B 錯，這是已選午餐的價值，不是被放棄的選擇；C 對，練習冊是阿朗最好的另一選擇，其價值是午餐的機會成本；D 錯，機會成本不是把已選與未選選項價值相加。
4. **C**。A 錯，不用把所有未選選項的價值加起來；B 錯，這是溫習的收益，不是被放棄選擇的價值；C 對，看電影是小美最想做的另一選擇，因此其價值是機會成本；D 錯，電影票價可能是金錢成本，但題目沒有說小美選擇看電影，她放棄的是看電影的機會。
5. **C**。A 錯，用時間作選擇也有機會成本；B 錯，機會成本只計價值最高的一個被放棄選擇，不是總和；C 對，這是本課使用的機會成本概念；D 錯，免費表示沒有金錢價格，不代表沒有其他被放棄的用途。

### 結構式題目

**1. 解釋稀少性如何令嘉怡需要作出選擇。（2 分）**

- 評分點：時間有限（1）；不能同時進行所有活動，需要在溫習、兼職、看電影之間選擇（1）。
- 示範答案：嘉怡只有三小時，時間有限，但她有溫習、做兼職和看電影等不同用途，因此不能同時選擇所有活動，需要作出取捨。

**2. 說出嘉怡溫習經濟的機會成本，並解釋你的答案。（2 分）**

- 評分點：指出做兼職（1）；指出兼職是她價值最高／最想要的另一選擇，因此放棄的收入 $240 是本題可量度的機會成本（1）。
- 示範答案：她溫習經濟而放棄做兼職；由於兼職是她最想選的另一活動，她放棄了可賺取的 $240。

**3. 評估朋友對機會成本的說法。（2 分）**

- 評分點：不應把所有被放棄選擇的價值相加（1）；若兼職是嘉怡價值最高的被放棄選擇，機會成本是放棄兼職所得的價值（本題為 $240）（1）。
- 示範答案：不正確。機會成本只計價值最高的一個被放棄選擇。若兼職是嘉怡最好的另一選擇，機會成本是放棄兼職的價值（本題為 $240），不用再加上看電影的價值。

### 課後練習參考

答案會因學生的真實選擇而不同。確認作答包含：已選選項、至少一個被放棄選項、其中價值最高的選項，以及說明為何該選項是機會成本。不要要求學生把未選選項全部相加。
