# 導師速記：Topic 5 短期生產

> 主修 B 第 2 課｜約 90 分鐘｜校內子題順序待核實

## 教學重點

- 短期的定義看有否固定投入；AP 是平均，MP 是新增投入帶來的額外產量。
- TP 的斜率反映 MP；TP 上升但愈平，表示 MP 正數但下降。
- MP 高於 AP 會拉高 AP，低於 AP 會拉低 AP；MP 正數不代表 AP 必上升。
- 遞減邊際報酬要求其他投入固定；解釋時連結共用／擠迫固定投入和 MP 下降。

## 流程提醒

| 時間 | 提醒 |
|---|---|
| 0–10 分鐘 | 重溫投入與產出；用「投入是否固定」診斷短期／長期。 |
| 10–25 分鐘 | TP、AP、MP 定義及計算；強調相鄰 TP 差額。 |
| 25–50 分鐘 | 先讀 TP 斜率，再看 MP、AP；用平均分比喻解釋 MP 拉動 AP。 |
| 50–68 分鐘 | 解釋固定咖啡機如何造成 MP 最終下降；強調 TP 未必下降。 |
| 68–83 分鐘 | 完成表格及結構題，追問數據和因果。 |
| 83–90 分鐘 | Quick Check；讓學生自行說明「MP 正、AP 降」的情況。 |

## 題目答案速查

- **表格（1–5 名）：**AP = 10、13、13、12、10.6；MP = 10、16、13、9、5。
- **Quick Check：**1. 短期，店面和座位固定。2. `60 ÷ 4 = 15` 件／人。3. `68 − 60 = 8` 件。4. MP 正數但下降。5. 共用固定咖啡機造成輪候／擠迫，額外產量下降。
- **MC：**1 C、2 B、3 B、4 B、5 C。第 3 題 MP=`48−39=9`，低於原 AP 13，故 TP 升而 AP 降。
- **結構題：**1. MP = 16、14、10、6 杯。2. AP=`52÷4=13` 杯／人／小時。3. 雪糕機固定，店員共用及輪候，新增店員額外產量下降。4. MP 仍正但下降，故 TP 仍升、升幅變小。5. 不正確：MP=6 < 原 AP=13，AP 由 13 降至 `58÷5=11.6`。
