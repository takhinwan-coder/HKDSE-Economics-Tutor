# 導師速記：Topic 5 短期成本

> 主修 B 第 3 課｜約 90 分鐘｜不教授成本曲線的一般關係

## 教學重點

- 固定／變動成本要按題目指定的時間範圍判斷；`TC = TFC + TVC`。
- 總額、平均額、邊際額分別回答「總共」、「每單位」、「新增一單位」。
- `AFC=TFC÷Q`、`AVC=TVC÷Q`、`AC=TC÷Q`、`MC=ΔTC÷ΔQ`；MC 不等於 TC÷Q。
- MP 下降可能令 MC 上升；只作因果連結，不講成本曲線間關係。

## 流程提醒

| 時間 | 提醒 |
|---|---|
| 0–10 分鐘 | 由短期投入固定連結到店租、店面等固定成本。 |
| 10–30 分鐘 | 分辨 TFC／TVC，按情境判斷而非死記成本名稱。 |
| 30–55 分鐘 | 由總額到平均額，再算相鄰產量的 MC；每步寫公式和單位。 |
| 55–70 分鐘 | 用「全部／每件／多一件」快速辨認成本問題。 |
| 70–85 分鐘 | 完成成本表及較難的固定成本變化題；不畫或比較成本曲線。 |
| 85–90 分鐘 | Quick Check；讓學生口述 MC 與 AC 的分別。 |

## 題目答案速查

- **成本表（Q=0–5）：**TC=60、90、110、126、142、165；AFC=—、60、30、20、15、12；AVC=—、30、25、22、20.5、21；AC=—、90、55、42、35.5、33；MC=—、30、20、16、16、23。
- **Quick Check：**1. 店租是短期固定成本。2. `$100+$80=$180`。3. MC=`165−140=$25`。4. 固定成本分攤到更多單位。5. MP 下降可能令多生產一單位需要更多可變投入，MC 因而上升。
- **MC：**1 A、2 C、3 C、4 B、5 B。
- **結構題：**1. TC=`$40、$60、$74、$88、$108`。2. MC=`$108−$88=$20`。3. Q=4 時 AFC=$10、AVC=$17、AC=$27。4. 短期固定投入不變，故 TFC 不變。5. 固定投入受限，MP 可能下降，多生產一單位需較多可變投入，MC 可能較高。6. MC 不變（$16）；AC 由 `$142÷4=$35.5` 升至 `$162÷4=$40.5`。
