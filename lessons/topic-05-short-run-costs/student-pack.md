## 1. 為甚麼「沒有生產」仍可能有成本？

短期內有些投入不能立即改變，例如店舖租約、固定設備。因此，即使一間店暫時沒有製作任何飲品，仍可能要支付租金。這些不隨產量改變的成本稱為**總固定成本（TFC）**。

相反，材料、按件計的包裝費或額外員工工時會隨產量改變。這些合共稱為**總變動成本（TVC）**。

```text
總成本（TC） = 總固定成本（TFC） + 總變動成本（TVC）
```

| 成本類別 | 短期內會否隨產量改變？ | 咖啡店例子 |
|---|---|---|
| 固定成本 | 不會 | 店租、固定咖啡機的租用費 |
| 變動成本 | 會 | 咖啡豆、紙杯、隨訂單增加的員工工時 |

> **判斷要看時間範圍。** 同一項支出在短期可屬固定成本，在長期卻可能改變；不要只背「租金一定固定」。

## 2. 成本表：先算總數，再算每單位

假設一間果汁店在短期的 TFC 是 $60。

先填總成本，再計算每單位成本和新增一杯的成本。分開填表可避免把總額、平均額和邊際額混在一起。

### 必用公式

```text
TC = TFC + TVC
AFC = TFC ÷ Q
AVC = TVC ÷ Q
AC = TC ÷ Q = AFC + AVC
MC = TC 的改變 ÷ Q 的改變 = TVC 的改變 ÷ Q 的改變
```

**為甚麼 MC 可用 TVC 的改變計？** 因為短期的 TFC 不變。多生產一杯所增加的 TC，完全來自 TVC 的改變。

### 逐步示範：由 2 杯到 3 杯

1. TC（2 杯）= `60 + 50 = $110`。
2. TC（3 杯）= `60 + 66 = $126`。
3. 第 3 杯的 MC = `126 − 110 = $16`；同樣是 `66 − 50 = $16`。
4. 3 杯時的 AC = `126 ÷ 3 = $42`。

## 3. 由生產到成本：MP 下降可能推高 MC

前一課提到，其他投入固定時，新增勞工最終要共用固定機器和店面，MP 可能下降。若每名新增勞工帶來較少額外產出，要多生產一杯便可能要用較多可變投入，新增一杯的 MC 因而上升。

```text
短期：其他投入固定
        ↓
新增勞工的 MP 可能下降
        ↓
多生產一杯可能需要較多可變投入
        ↓
新增一杯的 MC 可能上升
```

> 按更新版課程指引，本課不要求分析總成本、邊際成本與平均成本曲線的一般關係，也不要求比較短期與長期成本曲線。重點放在成本定義、成本表和單位辨別。

## 必記定義

| 詞語 | HKDSE 答題用語 |
|---|---|
| 總固定成本（TFC） | 在短期內不隨產量改變的總成本。 |
| 總變動成本（TVC） | 在短期內隨產量改變的總成本。 |
| 總成本（TC） | 總固定成本與總變動成本之和。 |
| 平均固定成本（AFC） | 平均每單位產出所分攤的固定成本。 |
| 平均變動成本（AVC） | 平均每單位產出的變動成本。 |
| 平均成本（AC） | 平均每單位產出的總成本。 |
| 邊際成本（MC） | 多生產一單位產出所增加的總成本。 |

## 考試答題提示

- **先看題目問總成本還是每單位成本。** TC 是總數；AC 是每單位。
- **計 MC 時比較相鄰兩列。** 不要用「TC ÷ Q」；那是 AC。
- **解釋 AFC 下降：**固定成本不變，但分攤到更多單位產出。
- **若題目問生產與成本：**交代固定投入、MP 下降及多生產一單位可能需要較多可變投入；不必延伸至成本曲線間的關係。
