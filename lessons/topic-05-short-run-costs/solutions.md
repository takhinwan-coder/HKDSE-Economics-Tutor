## 快問快答

1. 固定成本；在所指短期內，店租不隨當天有沒有產出而改變。
2. `TC = 100 + 80 = $180`。
3. `$165 − $140 = $25`。
4. TFC 不變，但會分攤到更多單位產出，因此每單位分攤的固定成本下降。
5. MC 通常上升。MP 下降時，多生產一單位可能需要較多可變投入，故新增成本增加。

## 選擇題

### 第 1 題
- **答案：A**
- **A 對：**短期內 TFC 不隨產量改變。
- **B 錯：**TVC 隨產量改變。
- **C 錯：**TC 包含 TVC，通常改變。
- **D 錯：**MC 可隨生產條件而改變。

### 第 2 題
- **答案：C**
- **A 錯：**$10 是 AFC。
- **B 錯：**$15 是 AVC。
- **C 對：**`TC = 50 + 75 = 125`，`AC = 125 ÷ 5 = 25`。
- **D 錯：**$125 是 TC，不是每單位的 AC。

### 第 3 題
- **答案：C**
- **A 錯：**`AC = TC ÷ Q`。
- **B 錯：**`MC = TC 的改變 ÷ Q 的改變`。
- **C 對：**總成本等於總固定成本加總變動成本。
- **D 錯：**`AFC = TFC ÷ Q`。

### 第 4 題
- **答案：B**
- **A 錯：**AFC 是固定成本除以產量，不是 $4。
- **B 對：**`AFC = 40 ÷ 4 = $10`。
- **C 錯：**$40 是總固定成本 TFC。
- **D 錯：**AFC 應以 TFC 除以產量計算。

### 第 5 題
- **答案：B**
- **A 錯：**短期內固定成本不必增加。
- **B 對：**遞減邊際報酬可能令每新增一單位產出需要較多可變投入，新增成本因而上升。
- **C 錯：**所有投入均可改變是長期的特徵。
- **D 錯：**TVC 通常隨產量增加，不會必定下降。

## 結構式題目

### 1. TC（2 分）
- Q = 0、1、2、3、4 時的 TC 分別為 `$40、$60、$74、$88、$108`。（每兩個正確數值 1 分）

### 2. 第 4 份的 MC（1 分）
- `$108 − $88 = $20`。

### 3. Q = 4 時的每單位成本（3 分）
- `AFC = 40 ÷ 4 = $10`（1）
- `AVC = 68 ÷ 4 = $17`（1）
- `AC = 108 ÷ 4 = $27`，或 `AFC + AVC = $27`（1）

### 4. TFC 不變（2 分）
- 短期內固定投入（例如店舖、固定設備）數量不變（1）；其成本不隨產量由 0 增至 4 而改變（1）。

### 5. 由 MP 至 MC（2 分）
- 在其他投入固定下，新增勞工共用固定投入，MP 可能下降（1）；要多做一份小食便可能需較多可變投入，所以新增一份的 MC 較高（1）。

1. 表中數值正確即可；可接受合理的小數表達。
2. MC 在第 4 單位開始上升：由 26 升至 28，然後升至 36。
3. AFC：TFC 不變但分攤至更多產量，故下降。MP 降低時，額外一單位產出可能需用較多可變投入，故 MC 上升。
4. `MC = 124 − 96 = $28`。MC 量度多生產一單位產出所增加的成本。
