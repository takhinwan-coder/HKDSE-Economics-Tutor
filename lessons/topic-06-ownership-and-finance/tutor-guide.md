# 導師備課筆記：Topic 6 廠商擁有權與融資

> 主修 B｜預計 70–75 分鐘｜本檔包含學生講義全部答案

## 教學目標

- 分辨公有制與私有制，舉出香港本地公有制機構例子。
- 比較獨資、合夥、私人有限公司和公眾有限公司的法律地位、擁有者數目和債務責任。
- 在具體情境中比較不同形式的利弊。
- 分清股票和債券，並從發行者及小投資者角度分析優缺點。

## 課前準備

- 白板寫明：「公有制 ≠ 公眾有限公司」及「股票＝擁有權；債券＝借款」。
- 不教成立公司所需文件、不分類股票或債券。
- 香港鐵路有限公司是上市、政府持有控制性股權的混合股權例子，不說成百分百公有。香港郵政或政府食水供應服務可作政府經營服務例子。

## 課堂流程

| 時間 | 教學環節 | 導師提示 |
|---|---|---|
| 0–8 分鐘 | 廠商與公有／私有 | 先問由誰擁有或控制，再辨認公有制和私有制。 |
| 8–27 分鐘 | 四種私人所有權 | 用「擁有者數目—法律地位—債務責任」三欄比較。 |
| 27–38 分鐘 | 情境比較利弊 | 給予「保留控制／擴大集資／降低個人責任」等目標，要求以特徵支持選擇。 |
| 38–54 分鐘 | 股票與債券 | 先講發行者的資金來源，再切換為小投資者的回報和風險。 |
| 54–64 分鐘 | Worked example | 讓學生按店主籌款情境逐步比較股票與債券。 |
| 64–72 分鐘 | 練習 | 選做結構題；評分重點是比較與因果，不只列名詞。 |
| 72–75 分鐘 | Exit ticket | 口頭問「股東／債權人」「有限／無限責任」各一題。 |

## 必須教會及範圍界線

- 獨資一名擁有者；一般合夥兩名或以上；不用教授合夥分類。
- 私人／公眾有限公司均是獨立法律個體，股東通常有限責任；私人公司股份不向公眾發售，公眾公司可向公眾發售。
- 公有制的本地例子須準確；「公眾有限公司」不是政府所有的同義詞。
- 股票代表擁有權；債券代表借款。分別說明發行者和投資者的利益、成本和風險。
- 不教授成立商業單位文件或股票／債券的分類。

## 預期困難與補救

| 常見誤解 | 補救提示 |
|---|---|
| 把公眾有限公司當成政府所有 | 問「誰持有股份？公司可否向公眾發售股份？」 |
| 有限責任代表不會損失投資 | 釐清有限的是股東對公司債務的責任，不是股價風險。 |
| 債券持有人是公司股東 | 問「購買債券後是借錢給公司，還是擁有公司一部分？」 |
| 發行股票無代價 | 追問原股東的擁有權比例、投票權可能如何改變。 |
| 債券利息固定就沒有風險 | 提醒違約及通脹風險，勿說債券保本。 |

## 學生講義答案

### 快問快答

1. 公有制由政府擁有或控制；私有制由私人擁有。
2. 不同。公有制說明政府擁有／控制；公眾有限公司是可向公眾發售股份的私人公司形式。
3. 私人有限公司和公眾有限公司的股東通常享有限責任。
4. 獨資只有一名東主，一般無限責任；一般合夥由兩名或以上合夥人共同擁有，合夥人一般無限責任。
5. 股票投資者是股東／擁有人；債券投資者是債權人。

### 選擇題

1. **A。**一人擁有的私人業務是獨資；合夥至少兩人；有限公司是獨立法律個體；公眾有限公司可向公眾發售股份。
2. **A。**公有制由政府擁有／控制；公眾有限公司可向公眾發售股份但不因此變成公有制。B 錯把上市與政府全資混為一談；C 不符合公眾公司可由多位股東持有；D 並非公有制定義。
3. **B。**兩種有限公司股東通常有限責任；A、D 描述無限責任；C 錯，股東正是持有股份的擁有人。
4. **B。**發債是借款，須按條款付息和還本；A 是股票投資者的身份；C 是發股可能稀釋投票比例；D 錯，債務仍帶來風險。
5. **B。**股票有股息及資本增值機會，也有無股息和股價下跌風險；A、C 把股票說成固定回報；D 錯，投資有市場風險。

### 結構式題目

1. 一名店主擁有（1）；東主一般承擔無限責任（1）。
2. 公司與股東是分開的法律個體（1）；股東通常只承擔投資額內的損失，屬有限責任（1）。
3. 私人有限公司股份不向公眾發售、轉讓受限制（1）；公眾有限公司可向公眾發售股份，較易向較廣投資者集資（1）。
4. 好處：不會稀釋股東擁有權／投票控制（1）；代價：須按約定支付利息及償還本金（1）。
5. 股票：可能收股息或獲資本增值（1），但股價可跌或無股息（1）。債券：可收約定利息（1），但發行者可能違約／通脹削弱實質回報（1）。

### 課後練習

1. 合夥（1）；兩位擁有者，一般合夥人通常承擔無限責任（1）。
2. 公司成為獨立法律個體（1）；股東通常有限責任，只承擔投資額內損失（1）。
3. 股票好處：不需固定還本／可籌長期資金；代價：稀釋擁有權或投票權。債券好處：不稀釋控制權；代價：須付息還本。每種資金方式各一項合理好處及代價（4）。
4. 股票風險：價格下跌或無股息；債券風險：違約或通脹侵蝕固定利息。每項 1 分。

## 課後跟進

- 觀察學生能否清楚分辨公有制／公眾有限公司和股東／債權人。
- 本課完成後仍要核對規模、結合和 Firm Objectives，才考慮主修 B 的完成狀態。
