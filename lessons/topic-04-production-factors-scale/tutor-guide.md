# 導師備課筆記：廠商與生產（一）——投入、生產力與分工

> 主修 B 第 1 課｜預計課堂：65–75 分鐘｜學校進度：首課涵蓋校內筆記 Ch.03「生產和分工」及 Ch.04「生產要素」

## 教學目標

- 學生能依照資源在生產中的角色，分類四種生產要素，而非靠背誦物件名稱。
- 學生能計算勞動生產力，並清楚說出它與總產量不同。
- 學生能以一個因果鏈解釋分工如何影響勞動生產力，並提出一項合理限制。
- 為第 2 課的短期生產、總產量／平均產量／邊際產量圖表建立「投入與產出」的語言基礎。

## 課前準備

## 課堂流程

| 時間 | 教學環節 | 導師提示／檢查理解 |
|---|---|---|
| 0–7 分鐘 | 診斷及引入 | 問：「一杯手搖飲要甚麼才做得到？」把答案寫進投入／過程／產出三欄；順帶核實學校已教範圍。 |
| 7–20 分鐘 | 生產與四種生產要素 | 由茶飲店例子連結 Ch.03 的生產情境與 Ch.04 的資源分類。每次追問「它在這裡做甚麼？」再分類；比較現金、封口機、店主的決策。 |
| 20–34 分鐘 | 產量與勞動生產力 | 先讓學生猜甲、乙餅店誰較有效率，再要求她算「每人每小時」。板書公式及單位。 |
| 34–47 分鐘 | 分工和專門化 | 用網店訂單流程，請學生畫箭咀；要求她說出一個機制，而不是只說「更快」。 |
| 47–57 分鐘 | 圖表及工具化活動 | 先分享講義圖 2，問「哪一間總產量較大？哪一間每名工人產量較大？」；再在 Desmos／Sheets 輸入兩三組「勞工數目、總產量」。只確認橫、縱軸和單位；預告第 2 課會分析 TP／AP／MP。 |
| 57–68 分鐘 | 結構式題目 | 學生先完成第 1、2 問；第 3 問用「原因 → 每位勞工 → 結果」句框口答。 |
| 68–75 分鐘 | Quick Check、功課及下課預告 | 用第 2、3、5 題檢查。預告第 2 課會問「增加一名工人時增加多少產出」，不要先要求背術語。 |

## 必須教會

- 生產要素按**功能**分類；資本是人造且協助生產的物品，並非所有金錢或物品。
- 勞動生產力是「總產量 ÷ 勞工數目」；比較不同規模廠商時必須先算比率。
- 分工提高生產力的可解釋機制：熟能生巧、減少工作轉換時間、利於使用專門機器。
- 分工的效果有條件：市場規模、協調成本和工作單調均可限制其好處。

## 可選內容

- 若學生已能流暢分類，省略更多生產要素例子，改花時間在結構式第 3、4 問。
- 若工具或網絡不便，跳過 Desmos，改在白板列出橫軸／縱軸；切勿犧牲生產力計算與因果解釋。
- 本課集中校內 Ch.03、Ch.04 中與 Topic 4 生產有關的內容；如學生筆記另含私有／公共物品，留待 Basic Economic Concepts 課題處理。

## 預期困難與補救

| 學生可能的錯誤／疑問 | 追問或解釋方式 |
|---|---|
| 把金錢一律寫成資本 | 問：「這張 $100 鈔票直接做了哪一道工序？」再問「用它買入封口機後呢？」 |
| 把土地只理解為農地 | 追問店舖可否離開所在地運作，引出地點／天然資源。 |
| 認為總產量較高就一定較有效率 | 先遮住總產量，問「兩間店每人各做多少？」再寫公式及單位。 |
| 只寫「分工令效率提高」 | 追問：「哪一步少了時間？工人因此可以做多了甚麼？」要求補回中間機制。 |
| 以為分工永遠有利 | 問一名員工的小店如何分成十個工序；引導到市場小、協調和重複工作的限制。 |

## Zoom 教學提示

- 分享講義圖 1，用 Zoom 註解讓學生圈出「投入」中的電單車、外賣員、店主決策所屬要素；她說理由後才揭示答案。
- 螢幕分享 Desmos／Sheets 時，先讓學生指定軸名稱，再由導師輸入資料；避免導師單向展示完成圖。
- 叫學生以完整句完成句框：`因為＿＿，所以每名工人在同一時間＿＿，因此勞動生產力＿＿。`
- 需要快速診斷時，在聊天室請她只輸入一個數字：`120 ÷ 4 = ?`；答完才問該數字的單位。

## 香港生活例子／討論問題

- 茶飲店的封口機、店員、店舖位置和店主的擴張決定，各屬哪種生產要素？
- 速遞平台把取件、路線安排和送件分給不同崗位，有何效率好處？何時可能出現協調問題？
- 地鐵站附近的店舖位置為何可視為土地？提醒學生：分類按資源性質，不是按是否「一大片農田」。
