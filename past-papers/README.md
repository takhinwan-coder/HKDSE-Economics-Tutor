# 歷屆試題

在此保存導師提供、供本 repository 備課使用的歷屆試題原檔。現有檔案已按 14 個課題分開；先看 [`index.md`](./index.md) 選取本課相關 PDF。無需先把各課題卷合併或拆頁。

## 建議整理方式

- 保留原始掃描 PDF 不變；若之後新增整份原卷或題目摘錄，記錄來源檔名和頁碼，避免重複保存同一內容。
- 目前索引到課題和 PDF；只有在某週實際採用題目並核實出處後，才補唯一 ID（例如 `HKDSE-2023-P1A-Q05`）、卷別、題號及頁碼。
- 當課材料只查本課相關的課題 PDF 和題目，不需要把全部歷屆試題載入對話。
- 可以在每週材料中整理題目的考點和答題技巧，清楚標示原題來源。
