# 學校課程來源

把 HKDSE syllabus 和課程參考文件放在這裡，並保留原檔名/版本，方便追溯來源。目前已有文件清單請參閱 [`index.md`](./index.md)。

學生的校內筆記已放在 [`student-notes/`](./student-notes/)，並在 [`index.md`](./index.md) 登記。備課時只查閱本課相關章節；筆記中的頁碼或校內術語若未核實，須明確標示待確認。

## 使用原則

- 學校提供的進度、術語與範圍優先於通用教材模板。
- syllabus/課程指引是課程範圍參考；學生筆記是校內教學脈絡的補充。若兩者用語或次序不同，保留來源並標示待核，不要默默把其中一方當成另一方。
- Agent 備課時只提供**本課相關的頁面、摘錄或檔案**；不必每次載入整份 syllabus。
- 每課的 `metadata.md` 記錄相關文件名稱、頁碼/章節及版本，讓材料可以追溯。
- 不確定學校要求或材料有矛盾時，先標明並請導師核實，不自行推定。
- 存放前遮蓋學生姓名、學校帳戶、聯絡方式、學號及其他不必要個人資料；不要把這些資料複製到生成的教材或索引。
