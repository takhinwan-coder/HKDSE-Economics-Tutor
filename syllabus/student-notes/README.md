# 學生校內筆記與教材

學生的校內課堂筆記已存放在此資料夾，檔案清單見 [`../index.md`](../index.md)。**目前備課範圍只需查看與該課有關的章節**；沒有必要一次整理或轉錄整套筆記。

## 存放方式

- 保留原件的內容和可辨認的檔名；可加日期或單元，例如 `2026-10_topic-name.pdf`。
- 可提供整份單元筆記，之後每課只引用相關頁面；若檔案很大，也可只放本課相關章節。
- 在 [`../index.md`](../index.md) 登記檔名、簡短用途、日期/版本及頁數（如已知），不必逐頁轉錄或預先整理全部內容。
- 備課時只查看與本課課題相關的檔案或頁面。每課材料記錄所用來源和頁碼，方便之後核對。
- 筆記模糊、缺頁、用語不清或與 syllabus 不同時，標示待核並詢問導師，不要猜讀或自行重寫成「學校要求」。

## 個人資料與分享

- 上傳前盡量遮蓋學生姓名、學校帳戶、聯絡方式、學號、班別名單、批改中可識別學生的資訊等不必要個人資料。
- 不要把可識別學生的資訊寫入課程索引、教材或常見錯誤紀錄。
- 本 repository 預設為本機工作資料夾；若日後考慮推送到遠端或分享給他人，先確認你有權分享相關學校材料，並移除個人資料。
