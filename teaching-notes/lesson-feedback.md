# 跨課堂教學調整

根據導師課後觀察更新；只保留可直接改進教學的匿名化資訊。

## 學習支援

- 學生較能掌握定性解釋；遇到數值題（特別是遞減邊際報酬）時，先完整示範，再逐步撤走提示。
- 每次計算固定採用五步：找已知資料和所求 → 選公式 → 代入 → 計算 → 寫單位並解讀結果。
- TP/AP/MP 題要清楚分開：TP 是總產量；AP 是 TP 除以投入數目；MP 是相鄰兩個 TP 的差額。用逐行計算及小數據表練習，並追問「數值代表甚麼」。

## 教材輸出與設計

- 每課只有兩份教學筆記：學生版 `student-pack.md` 和導師版 `tutor-guide.md`。
- 導師版附齊學生版每題答案、MC 各選項解釋、計算步驟和結構式題目評分點；不要另建一份 solutions 文件。
- 學生版以清晰層級、短段落和有意義的 SVG/流程圖增加視覺提示。圖像解釋概念，不作裝飾。
- 匯出 PDF 後逐頁檢查段落、表格、圖片和標題有否被截斷或分拆；Markdown 顯示正常不代表 PDF 換頁正常。
